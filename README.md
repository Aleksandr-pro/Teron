# Teron v2.0.0 — Нативное Android-суперприложение

**Teron** — нативное Android-приложение (**100% Kotlin + Android SDK, без WebView и веб-обёрток**), объединяющее автономный мессенджер без интернета (**AirMesh**), почтовый клиент (**IMAP/SMTP + AirMesh**), некастодиальный мультисетевой криптокошелёк (**TeronPay BIP-39**), локальный аудиоплеер, оптический обмен ключами (**SunCode & QR**) и прикладные мини-сервисы.

## 📈 Teron Signals — торговые сигналы (отдельное приложение)

Нативный помощник трейдера: сигналы **BUY / SELL / HOLD** (включая Strong) по выбранным криптопарам на таймфреймах от **1 минуты до 1 месяца**, на основе технического анализа **TradingView** (рейтинг `Recommend.All` + 17 индикаторов: RSI, MACD, EMA/SMA, ADX, Ichimoku и др.), с **силой сигнала в %** по каждой паре. Без API-ключей и регистрации.

## Что нового в Teron v2.0.0

1. **Строгий продуктовый интерфейс и векторная графика (SVG / VectorDrawable):**
   - Архитектурная цветовая система **Graphite Carbon (`#0B0D11` / `#151922`)** и **Pure Slate (`#F7F8FA` / `#FFFFFF`)** с акцентом **Cobalt (`#2563EB`)**, тонкими разделителями `1dp` и табличными числами (`tnum`).
   - 70 геометрических векторных иконок `VectorDrawable` (`24×24dp`) во всей навигации, карточках, плеере, чатах и модальных окнах — без эмодзи и декоративных градиентов.

2. **Реальный некастодиальный криптокошелёк TeronPay (BIP-39 / BIP-32 / BIP-44 / BIP-84):**
   - Генерация и импорт стандартной **12/24-словной BIP-39 фразы** (совместимой с Trust Wallet, MetaMask, Electrum, Ledger).
   - Локальная деривация ключей `secp256k1` и реальных публичных адресов:
     - **Bitcoin Native SegWit (`bc1q...`, `m/84'/0'/0'/0/0`)**
     - **Ethereum и USDT ERC-20 (`0x...`, EIP-55, `m/44'/60'/0'/0/0`)**
     - **TRON и USDT TRC-20 (`T...`, Base58Check, `m/44'/195'/0'/0/0`)**
   - Живая синхронизация балансов, курсов (`USD` / `RUB`) и истории транзакций напрямую из блокчейн-узлов (`mempool.space` / `blockstream.info`, Ethereum JSON-RPC + Blockscout, `trongrid.io`).
   - Локальная криптографическая подпись транзакций RFC-6979 ECDSA (`secp256k1`) и отправка в Mainnet, а также генерация контрастных QR-кодов (`ISO/IEC 18004`) для приёма переводов.

3. **Реальные пользовательские данные без заглушек:**
   - При первом запуске открывается экран создания профиля или восстановления аккаунта по BIP-39 Seed-фразе.
   - Полноценный почтовый клиент **IMAP SSL (993) / SMTP SSL & STARTTLS (465/587)** с автонастройкой для Gmail, Яндекс, Mail.ru, iCloud, Outlook и корпоративных серверов, а также офлайн-доставкой писем `@teron.mesh`.
   - Импорт реальных контактов из телефонной книги Android, по QR/SunCode и через радиоэфир **AirMesh** (`Bluetooth LE` + `Wi-Fi LAN P2P`).
   - Локальный аудиоплеер с приоритетом реальной медиатеки смартфона (`MediaStore.Audio`) и выбором файлов через системный проводник.
