# ⚡ Teron — Автономное нативное Android-суперприложение

**Teron** — полноценное нативное Android-приложение (**100% Kotlin + Android SDK, без WebView и веб-обёрток**), объединяющее автономный мессенджер без интернета (**AirMesh**), электронную почту (**Teron Mail**), офлайн-музыку и синтезатор (**Teron Sound**), лучевые визуальные коды (**SunCode**), тренажёр китайского языка по ассоциациям (**Ханьцзы Додзё**), культурную игру **Маджонг** и криптокошелёк **TeronPay**.

## 🚀 Ключевые технологии и сервисы Teron

### 1. 📡 Протокол `AirMesh` — связь между смартфонами без интернета и сотовой сети
- **Двойной радиотранспорт:**
  - **Bluetooth Low Energy (BLE Mesh):** фоновое вещание маяка (`BluetoothLeAdvertiser`), радар узлов с оценкой дистанции по `RSSI` (`BluetoothLeScanner`) и обмен зашифрованными кадрами через `BluetoothGattServer` / `BluetoothGatt` (`UUID 00007e20-...`).
  - **Локальный Wi-Fi / Хот-спот P2P:** автоматическое обнаружение смартфонов по UDP-маякам (`47920`) и передача пакетов по TCP (`47921`) даже без SIM-карты и доступа в интернет.
- **Эстафетная передача (Multi-Hop Relay + Store & Forward):**
  - Сообщения, письма и крипто-чеки передаются по цепочке от телефона к телефону (по умолчанию до **4 переходов**, для канала `#sos` — до **6 переходов**, охват до **750–800 метров**).
  - Если рядом никого нет, зашифрованный пакет сохраняется в локальной очереди `mesh_relay_queue` и уходит автоматически при появлении первого узла Teron поблизости.
- **Сквозное шифрование (Zero-Server E2EE):**
  - Ключи **NIST P-256 (`ECDH` + `HKDF-SHA256`)**, шифрование полезной нагрузки **AES-256-GCM** и проверка подлинности отправителя **ECDSA (`SHA256withECDSA`)**. Промежуточные смартфоны-ретрансляторы не могут прочитать переписку.

### 2. ☀️ Лучевые коды `SunCode` (визуальная замена QR-кодам)
- 64 гармонических радиальных луча вокруг аватара кодируют ваш `Node ID` и отпечаток публичного ключа `ECDH P-256`.
- Живой оптический видоискатель на базе **Android Camera2 API (`TextureView`)**, экспорт PNG-карточки со встроенной криптографической меткой `TeronSunCode` и поддержка прямых ссылок `teron://contact?...`.

### 3. ✉️ Почтовый клиент `Teron Mail` (`@teron.mesh` + SSL IMAP)
- Полноценный почтовый ящик (**Входящие**, **Отправленные**, **Очередь AirMesh**, **Избранное**, мгновенный поиск, приоритеты писем).
- Доставка писем напрямую между устройствами без интернета через AirMesh + опциональная проверка подключения к внешним SSL IMAP-серверам при появлении сети.

### 4. 🎵 Музыкальный сервис `Teron Sound`
- **5 встроенных офлайн-композиций** (полифонический DSP-синтез 16-бит PCM WAV прямо на устройстве без интернета: *«Огни Находки»*, *«Ночная Тайга»*, *«Шёпот Гучжэна»*, *«Орбита AirMesh»*, *«Тихий Океан»*).
- Сканирование локальной фонотеки смартфона (`MediaStore.Audio`) и импорт любых аудиофайлов (`MP3`, `FLAC`, `WAV`, `M4A`, `OGG`), 60fps визуализатор спектра и сквозной мини-плеер.

### 5. 🧩 Мини-приложения экосистемы
- **🐼 Ханьцзы Додзё:** 24 базовых китайских иероглифа с образными ассоциациями, Пиньинь, офлайн-озвучкой `TextToSpeech`, холстом для каллиграфии пальцем по сетке `米字格` и интервальной викториной.
- **🀄 Маджонг Культура:** нативный пасьянс на 36 костей с подсказками, комбо-очками и культурной энциклопедией китайских символов.
- **💎 TeronPay:** криптокошелёк с 12-словной мнемонической фразой и мгновенными офлайн P2P-переводами по AirMesh, заверенными цифровой подписью ECDSA.
