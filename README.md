# Teron v2.1.0 — Нативное Android-суперприложение

**Teron** — нативное Android-приложение (**100% Kotlin + Android SDK, без WebView и веб-обёрток**), объединяющее мессенджер со сквозным шифрованием (**Глобальная E2EE-сеть Teron + автономный радиоэфир AirMesh**), синхронизацию контактов по **SHA-256**, почтовый клиент (**IMAP/SMTP + AirMesh**), некастодиальный мультисетевой криптокошелёк (**TeronPay BIP-39**), локальный аудиоплеер, живой оптический сканер (**SunCode & QR**) и прикладные мини-сервисы.

## Что нового в Teron v2.1.0

1. **Полноценная синхронизация телефонной книги и глобальный поиск людей с Teron:**
   - Приватная синхронизация телефонной книги смартфона (`READ_CONTACTS`): канонизация номеров (`+7`, `87...`, `89...`, международный E.164) и сопоставление по криптографическим хешам **SHA-256** без передачи открытых номеров.
   - Автоматическое разделение телефонной книги на друзей, **у которых уже установлен Teron** (с мгновенной подгрузкой их `ECDH P-256` ключей шифрования), и контакты, доступные для приглашения в один тап.
   - Живой поиск реальных пользователей Teron в реальном времени по **имени, `@нику`, номеру телефона или `TRN-ID`** без сброса клавиатуры и фокуса ввода.

2. **Гибридный транспорт E2EE (Интернет-релей + автономный радиоэфир AirMesh):**
   - Мгновенная доставка сообщений, подтверждений `ACK` и писем со сквозным шифрованием (`ECDH P-256` + `AES-256-GCM` + подпись `ECDSA`) между любыми городами и мобильными сетями, а при отсутствии интернета — напрямую по **AirMesh**.
   - Улучшенное локальное обнаружение устройств рядом: разделение пакетов `Bluetooth LE Advertising` + `Scan Response` (устранено ограничение 31 байта на чипсетах Android), `Wi-Fi Multicast (239.255.79.20)` и zero-config обнаружение **`NsdManager` mDNS (`_teron._tcp.`)** с двусторонним обменом ключами по TCP.

3. **Живой оптический автосканер SunCode:**
   - Встроенная **10×10 оптическая матрица** с кодом узла и контрольной суммой **CRC-16-CCITT** (инвариантна к повороту на `0°/90°/180°/270°`), распознаваемая в реальном времени с камеры `Camera2` и со скриншотов/сжатых JPEG-изображений из мессенджеров.
