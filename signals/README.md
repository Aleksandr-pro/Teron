# Teron Signals — нативное Android-приложение для торговых сигналов

Стадийное нативное Android-приложение (**100% Kotlin + Android SDK**, без WebView и без AndroidX),
получающее данные по криптопарам из **публичного сканнера TradingView**, считающее
технический анализ на выбранном таймфрейме и выдающее сигналы **BUY / SELL / HOLD**
(с уровнями **STRONG BUY / STRONG SELL**) для пар из вашего списка отслеживания.

Пакет: `app.teron.signals` · minSdk 24 · targetSdk 34 · текущая версия **1.1.0 (versionCode 2)**.

## Скачать и обновлять

- **[⬇ Прямая ссылка: TeronSignals-v1.1.0.apk](https://raw.githubusercontent.com/Aleksandr-pro/Teron/main/releases/TeronSignals-v1.1.0.apk)** — ставится на Android 7.0+, при установке разрешите «установку из неизвестных источников» для браузера.
- **Обновления внутри приложения:** при запуске и по кнопке ⬇ в шапке экрана «Сигналы» приложение читает `releases/TeronSignals-version.json` из ветки `main`, сравнивает `versionCode` и, если вышла новая версия, предлагает скачать APK. Установка идёт **поверх** текущей версии — watchlist и настройки сохраняются.
- **Постоянный ключ подписи:** все APK (и Signals, и суперприложение Teron) подписываются одним релизным ключом `keystore/teron-release.keystore` (сертификат `SHA-256: 58cdf12e30609060c789bf2ec9e8836aad99c5451774515ad8851013410d1cd1`). Этот ключ **никогда не менять и не пересоздавать** — иначе Android не даст обновить уже установленные копии. При выпуске новой версии: поднять `versionCode`/`versionName` в `signals/src/main/AndroidManifest.xml`, собрать `bash scripts/build-signals-apk.sh`, обновить `releases/TeronSignals-version.json` — приложение у пользователей само предложит обновление.

## Возможности

- **Таймфреймы**: `1M, 5M, 15M, 30M, 1H, 2H, 4H, 1D, 1W, 1M` — переключаются строкой чипов.
- **Список отслеживания (watchlist)**: поиск по символу/базовой валюте, включение/исключение пар,
  добавление по символу вручную. Хранится локально.
- **Сводный сигнал** для каждой пары:
  - рейтинг TradingView (`Recommend.All`, −1..+1),
  - собственный агрегированный анализ индикаторов,
  - итоговый сигнал (взвешенная комбинация).
- **Разбор по индикаторам**: RSI, MACD, Стохастик, Stoch RSI, CCI 20, ADX (сила тренда),
  Awesome Oscillator, Momentum, Williams %R, Ultimate Oscillator, BB Power,
  EMA/SMA (5–200), Ichimoku Cloud, VWMA, Hull MA 9.
- **Экран детали пары**: цена, изменение 24h, сводный сигнал, счётчик бычьих/медвежьих
  индикаторов и значение по каждому индикатору с цветовой индикацией.
- Автоматический выбор ~14 самых ликвидных пар при первом запуске.

## Источник данных

Приложение использует **публичный, анонимный эндпоинт сканнера TradingView**, на который
ссылается сам сайт-скриннер:

```
POST https://scanner.tradingview.com/{market}/scan
```

- `{market}` пробуется по очереди: сначала **`cex`** (пары централизованных бирж), затем
  **`crypto`** (агрегированный) — так приложение работает даже если один рынок недоступен.
- **Не требуется API-ключ, логин или подписка.**
- Данные — снимок (snapshot); обновить можно кнопкой «Обновить».
- Значения индикаторов запрашиваются со **суффиксом таймфрейма**, например
  `RSI|60`, `MACD.macd|1W`, `Recommend.All|240`.

## Как считается сигнал

1. Для пары на выбранном таймфрейме запрашиваются значения индикаторов TradingView.
2. Рейтинг TradingView `Recommend.All` (−1..+1) превращается в сигнал:
   `≥ 0.6 → Strong Buy`, `≥ 0.2 → Buy`, `> −0.2 → Hold`, `> −0.6 → Sell`, иначе `Strong Sell`.
3. Собственный рейтинг: каждая индикаторная проверка даёт `+1` (бычий), `−1` (медвежий) или `0`;
   среднее взвешенное значение — это «локальный» сигнал.
4. **Итоговый сигнал = 0.6 · TradingView + 0.4 · локальный.**

## Сборка

Сборка использует тот же кастомный toolchain, что и суперприложение Teron
(Kotlin-компилятор + aapt2 + D8 + apksigner, без Gradle):

```bash
bash scripts/build-signals-apk.sh
```

Готовый подписанный пакет: `releases/TeronSignals-v<versionName>.apk` (имя выводится из манифеста, чтобы не расходиться с проверкой обновлений).

Универсальный сборщик (по умолчанию сохраняет прежнее поведение для Teron):

```bash
bash scripts/build-apk.sh [модуль] [пакет] [output.apk]
```

```
    ├── SignalsApp.kt          # Application, bootstrap каталога пар
    ├── core/
    │   ├── Theme.kt           # палитра и форматчики
    │   ├── Models.kt          # Timeframe, Signal, PairInfo, PairSignal, IndicatorReading
    │   ├── SignalEngine.kt    # индикаторы → сигнал
    │   └── Prefs.kt           # watchlist / таймфрейм
    ├── data/
    │   ├── Http.kt            # HttpURLConnection + фоновая очередь
    │   └── TradingViewApi.kt  # сканнер, парсинг, нормализация пар
    └── ui/
        ├── Components.kt      # переиспользуемые виджеты
        └── Screens.kt         # SignalsScreen / PairsScreen / DetailScreen
```
